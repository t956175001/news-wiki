# frontend

Vue 3 + TypeScript + Vite client for news-wiki. See the repo root `README.md`
and `docs/ARCHITECTURE.md` (sections 4 and 6) for the API contract and routes.

```bash
npm install
npm run dev              # http://localhost:5173, proxies /api to :8000
npm run lint
npx vue-tsc --noEmit
npm run test
npm run build
```
